## Сертификат и продление

Сертификат содержит IP Address:186.246.28.195, выдан Let's Encrypt YE2.
Срок окончания на момент проверки: 29 октября 2026 года, 00:32:17 по Москве
(28 октября, 21:32:17 UTC). Следующее успешное продление изменит эту дату.

Использовал официальный Certbot 5.8.0. Docker-образ закреплён по digest в
scripts/renew-https.sh. Сертификат и ключ находятся только на сервере,
в /etc/letsencrypt; Nginx получает каталог только для чтения.

Таймер zag-flow-certbot.timer проверяет продление четыре раза в сутки:
00:00, 06:00, 12:00 и 18:00 UTC, с задержкой до 30 минут. После успешного
продления сценарий проверяет конфигурацию и перечитывает сертификат в Nginx.
Одновременный запуск сценария блокируется через flock.

Пробное продление завершилось успешно; deploy-hook проверил и перечитал Nginx.
Затем отдельно запустил системную службу: Result=success, ExecMainStatus=0.
Фактическое очередное продление в будущем ещё не наступило.

Проверка расписания и результата:

```bash
systemctl list-timers zag-flow-certbot.timer --no-pager
systemctl status zag-flow-certbot.service --no-pager
journalctl -u zag-flow-certbot.service -n 40 --no-pager
```

Пробное продление с проверкой перечитывания Nginx:

```bash
/usr/local/sbin/zag-flow-renew-https --dry-run --run-deploy-hooks
```

## Обслуживание конфигурации

На VPS в .env добавлен COMPOSE_FILE=docker-compose.yml:docker-compose.https.yml,
поэтому обычные команды Compose учитывают TLS-конфигурацию. Публичный HTTP-порт
по-прежнему задаётся HTTP_PORT=80, HTTPS опубликован на 443.

HTTP обслуживает ACME-проверку и технический /healthz. Остальные HTTP-пути
перенаправляются на тот же IP по HTTPS с кодом 308. Порт 22 остаётся для SSH.
Порты Backend и PostgreSQL наружу не публикуются; pgAdmin привязан к localhost.

Не копировать конфигурацию с сертификатом в новый сервер до выпуска сертификата:
Nginx не запустится, если файлов fullchain.pem и privkey.pem ещё нет.

При проверке каталог /opt/zag-flow содержал версию 0.2.0.
Версию 0.3.0 развернул в отдельном каталоге /opt/zag-flow-admin с отдельным
Compose-проектом и томом базы. Шлюз направлял запросы /next/ в новый контур.

## Откат к HTTP при необходимости

Откат выполняется только при осознанном решении вернуть прежнюю конфигурацию.
Он не требует восстановления или удаления базы данных.

1. Сохранить текущую TLS-конфигурацию отдельно.
2. Остановить таймер zag-flow-certbot.timer.
3. Восстановить .env и docker-compose.yml из закрытой резервной копии.
4. Пересоздать только Frontend командой с явным базовым файлом:
   docker compose -f docker-compose.yml up -d --no-deps --no-build frontend.
5. Проверить HTTP, API и доступность прежних данных.

Закрытый ключ и резервные копии не включаются в публичные материалы.
