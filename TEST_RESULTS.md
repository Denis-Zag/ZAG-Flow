- Windows 10;
- Python 3.12 в проектном виртуальном окружении;
- Chromium-совместимый браузер;
- JavaScript проверен встроенным синтаксическим анализатором Node.js.

| Проверка | Результат |
|---|---|
| Backend-тесты | `4 passed in 3.81s` |
| Синтаксис JavaScript | успешно |

## Обнаруженные и исправленные проблемы

1. Первая локальная загрузка образов прерывалась из-за временного DNS-сбоя Docker Hub. Повторная загрузка завершилась успешно.
2. Watchtower 1.7.1 использовал устаревшую версию Docker API. В окружении закреплена совместимая версия API `1.44`.
3. pgAdmin нуждается одновременно во внутренней сети PostgreSQL и localhost-публикации. Добавлена edge-сеть при сохранении привязки к `127.0.0.1`.
4. CSS экрана успеха перекрывал атрибут `hidden`. Добавлено единое правило скрытия; цикл повторной отправки проверен.
5. На первом серверном запуске pgAdmin отклонял технический email с доменом `.local`. Серверная учётная запись заменена на синтаксически допустимый адрес, после чего контейнер запустился без перезапусков.

## Граница проверки

Домен и TLS-сертификат пока не настроены. Учебный сайт доступен по HTTP, поэтому реальные персональные данные через форму не передаются. Срок хранения, порядок удаления и отдельная политика обработки персональных данных сознательно отложены до коммерческой подготовки проекта.
